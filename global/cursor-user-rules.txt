When the user is creating a new project and the current folder has no AGENTS.md, install
repository governance before product code. Read REPO_GOVERNANCE_HOME from the environment; do not
guess its location. On Linux run new-governed-repo.sh. On Windows PowerShell run
new-governed-repo.ps1. Then establish PRD.md, fill project-specific policy placeholders, configure
the project checks, create a branch, and commit governance before implementation.

If AGENTS.md exists, do not re-scaffold. Read and follow it as the canonical repository policy.
Use a bounded SPEC.md for substantial work, not trivial edits. Project instructions do not grant
additional host access and are not the only security boundary; local Git hooks, CI, hosting
protections, and human governance approval remain in force.
